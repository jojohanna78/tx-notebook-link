# TX Notebook Link

Ce dépôt contient plusieurs notebooks Jupyter consacrés à l'étude des usages pédagogiques de notebook.link

## Contenu du dépôt

### Comparaison des bibliothèques de visualisation

(https://github.com/jojohanna78/tx-notebook-link/blob/main/Comparaison_librairies_visualisation.ipynb)

Ce notebook permettant de comparer différentes bibliothèques de visualisation.

### Étude des outils de visualisation STL

(https://github.com/jojohanna78/tx-notebook-link/blob/main/Etude_outils_visualisation_STL.ipynb)

Étude et expérimentation de différents outils permettant de visualiser des fichiers STL et des objets 3D dans un environnement JupyterLite.

### JupyterCards

(https://github.com/jojohanna78/tx-notebook-link/blob/main/Jupytercards.ipynb)

Exemple d'utilisation de JupyterCards pour créer des interfaces interactives sous forme de cartes dans un notebook.

### JupyterQuiz

(https://github.com/jojohanna78/tx-notebook-link/blob/main/Jupyterquiz.ipynb)

Exemple d'utilisation de JupyterQuiz afin de créer des quiz et des activités interactives directement dans un notebook.

### Widgets Jupyter

[Widget.ipynb](https://github.com/jojohanna78/tx-notebook-link/blob/main/Widget.ipynb)

Expérimentation des widgets interactifs afin de créer des interfaces permettant à l'utilisateur d'interagir avec les données et les visualisations.

## Environnement

Le dépôt contient un fichier d'environnement qui permet de recréer l'environnement nécessaire à l'exécution des notebooks : envrionment.yml

## Utilisation avec Notebook.link

Ce dépôt est public et peut être utilisé comme source pour Notebook.link.

Ouvrez l'url suivante du dépôt GitHub couplé avec notebook.link :

https://github.com/jojohanna78/tx-notebook-link/

Les notebooks disponibles dans le dépôt sont :
* `Comparaison_librairies_visualisation.ipynb`
* `Etude_outils_visualisation_STL.ipynb`
* `Jupytercards.ipynb`
* `Jupyterquiz.ipynb`
* `Widget.ipynb`
